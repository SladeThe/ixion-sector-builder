# Sector builder (modded mirror)

Offline mirror of N8Dawg's Ixion Sector Builder (Godot 3.5.1 HTML5 tool) with local UI mods.
Upstream content belongs to the author; `upstream/` keeps the pristine build.

## Layout & tooling

- `index.html` — runner for `file://` and HTTP: fetch shim, `canvasResizePolicy: 2`, embed script tags,
  tEXt inject/extract and save-picker helpers (ixion* functions).
- `upstream/index.html` — pristine upstream wrapper, archived; itch-hotlink-protected, unusable outside itch.io.
- `index.pck` — locally modded build (from `src/`); `index.wasm`/`index.js` stay upstream.
- `*.data.js` — generated by `rebuild-embeds.ps1`; regenerate, never edit.
- `upstream/index.pck` — pristine upstream pack (build 7047666).
- Tooling lives OUTSIDE this repo, in a sibling `tools/` dir next to the repo root:
  `godot-3.5.1/` (Godot 3.5.1 editor, matching the pack version), `gdre/` (GDRE Tools v2.6.4,
  decompiles packs to source), `icon-redraw/` (icon generation scripts). Get Godot from
  godotengine.org (3.5.1-stable win64) and GDRE from its GitHub releases.

## Run

Open `index.html` in any modern browser (double-click works, no server). It patches `fetch` to serve
`index.wasm`/`index.pck` from base64 `*.data.js`, which `file://` allows via script tags; over HTTP the
same page works as-is (this is how the live demo runs).

## Local mods

~1.5x larger grid than upstream, editor-style dock shell: top toolbar (cursor coords left, resource totals centered, Import/Export/Clear right),
left palette rail (fixed 4-column tiles), single right rail (LAYOUT CHECK at the top, hover info with wiki descriptions or the controls
hint pinned to its bottom). Frames keep a small gap so borders never collide. The grid fits the leftover center rect, so panels
never overlap it. Chrome scales with clamp(min(w/2560, h/1440), 0.8, 1.3); palette tile width scales with aspect (0.8 below 2.0, ramping to 1.0 at 2.4) to give the grid more width on narrow screens.
The check list fills the rail's free space and scrolls only on overflow. UI fonts render unfiltered at integer rects for crisp browser text.
Radial hover highlight (luminance-shifted gradient baked to a texture), Esc cancel. MMB on a placed stockpile cycles its stored resource
(Shift+MMB reverses) (none + 11 storable types), drawn as an icon in its top-left corner and saved in YAML as `resource:`.
LAYOUT CHECK lists errors (no Mess Hall / no Workshop / quarters below required workers, import overlaps / out-of-bounds) and warnings
(no Fire Station / DLS Center / Memorial / Infirmary, stored power < 700, quarters below 800; with an Alt Life Center present the 800-cap
warning reads as its partial-bonus case). Ctrl+O imports, Ctrl+S exports. Export saves a single PNG whose `tEXt` chunk (`ixion-layout`)
carries the YAML (save picker offers YAML too); Import accepts `.png` (embedded layout) and `.yaml`.
Rotation remembered per building type. Wall-only buildings cannot occupy the middle 8 top-wall cells (red glow).
Static UI: no zoom, no panning; scrolling only inside an over-long problems list.

Buildings use proper in-game names ("Stockpile - Small", "Battery - Tier 1"). Tiles keep full-word
aliases with explicit line breaks (`BuildingInfo.TILE_LABELS`) and per-category tile order
(`BuildingInfo.CATEGORY_TILES`). YAML layout: name + grid pos + size + optional resource per building (`LayoutIO.gd`).
PNG export renders the grid at 2x via an offscreen viewport (`GridRender.gd`) and embeds the YAML;
exported PNGs are self-contained layouts. Last file name persists in
`localStorage['ixion-builder-last-path']`.

## App map (`src/`)

- `Main.gd` — grid draw, dock shell (toolbar/palette/right rail), camera fit to the center rect, JS interop, import/export, wall zone, layout checks. `IXION_LAYOUT=<yaml path>` headless run loads a layout for UI screenshots.
- `Classes/Building.gd` — placement/move/rotate/delete logic, labels, stockpile resource cycling + icon.
- `Classes/BuildingInfo.gd` — categories, wiki descriptions, tile labels, tile order. Keys must
  exactly match `building_name` in `Buildings/*.tscn` (rename both sides together).
- `Classes/LayoutIO.gd` — YAML writer/parser; optional per-building `resource:` key.
- `Classes/GridRender.gd` — offscreen PNG renderer.
- Wiki audits: fandom HTML is Cloudflare-challenged - use `api.php` (action=parse/query) and
  `static.wikia.nocookie.net` for assets; no per-resource icon files exist there. User-verified
  game values beat the wiki.
- `Classes/SidebarButton.gd` — tile button; delegates to `Main.spawn_building`.
- `Buildings/*.tscn` — per-building `building_name`, `display_color`, `size`, `wall_locked`, `resources`.
- `IXION_SHOT=1` headless run saves a viewport screenshot to `shot.png` and quits; `IXION_HOVER_TEST=1`
  also places a hovered Stockpile - Large for highlight checks. `IXION_CONVERT=1` batch-renders YAML
  layouts from a sibling `sectors/` dir to PNGs (migration helper).

## Behavior invariants (regressions here froze the app before)

- Never call `button.make_building()` from `Building.gd`: imported buildings have `button == null`
  (Nil call each frame, `can_select` sticks false, app freezes). Chaining goes through
  `Main.spawn_building`; rotation memory lives in `Main.last_sizes` (written on rotate and on place).
- Cancel (RMB/Esc) releases `can_select` via `set_deferred`; a direct set lets a static building under
  the cursor see the flag flip mid-frame and delete itself on the same cancel click.
- Hover info: a building clears `Main.hover_building` only while it still owns it; an unguarded
  unhover let the old building overwrite the new hover when the cursor moves straight between two.
- Redirected stdout is block-buffered: an empty capture proves nothing. Bisect spins with File traces
  (`res://../trace.log`), not prints.
- `Directory.open` cannot escape `res://` via `..` (error 31) while `File.open` can; list sibling dirs
  via `ProjectSettings.globalize_path("res://") + "../../<dir>"`.
- PCK byte-greps only see string constants; method names (set_deferred, call_deferred) compile to
  nameless opcodes, so verify packs via string literals like js_eval payloads.
- PNG font tiers in `GridRender` by longest side in cells: <=3 -> 1.0x, >=9 -> 2.0x, else 1.5x;
  landscape names word-wrap via `wrap_words`, portrait names stack one word per line.
- JS is reachable only via `Main.js_eval` (returns null on desktop — guard web-only paths).
  Import polls `window.__ixion_import` each frame (`__ixion_import_error` flags bad PNGs); the
  tEXt inject/extract and save-picker helpers (ixion* functions) live in `index.html`.
- `showDirectoryPicker` was rejected (folder-only); `showSaveFilePicker` drives Export instead,
  with `a.click()` download fallback on non-Chromium browsers (Shift+Export/Ctrl+Shift+S = YAML).

## Godot 3.5 gotchas (each one cost real debugging time)

- GDScript errors are invisible on stdout; the only reliable sink is the engine log under the Godot
  app-data dir (`app_userdata/Ixion Builder/logs/godot.log`) — read it after every run.
- Runtime errors abort the entire GDScript call stack, but native-call argument errors (e.g.
  `add_child(null)`) do NOT abort the caller — a function can "succeed" while returning null.
- `Control.PRESET_FULL_RECT` is Godot 4; Godot 3 uses `PRESET_WIDE`.
- Godot 3 `draw_texture_rect()` needs the `tile` bool (3+ args); a 2-arg call is a parse error that kills the script and its preloaders, and headless runs spin silently.
- With anchor 1, positive `margin_right`/`margin_bottom` push outside the parent; use negatives.
- `sort_custom(InnerClass, "static_method")` silently corrupts arrays; bind an instance method.
- Functions containing `yield` return a `GDScriptFunctionState`; capture results via
  `yield(call(), "completed")`.
- An offscreen `Viewport` needs `render_target_update_mode = UPDATE_ALWAYS` or its texture is black.
- That same offscreen render makes desktop engine shutdown hang; the web build is unaffected.
  Never add a desktop auto-hook for PNG export — the browser is the real target.
- GDScript 1.0's analyzer hangs forever (no error printed) on an undefined identifier inside a function;
  if a headless run spins with no output, suspect a dangling identifier first.
- Godot writes raw escape sequences / non-UTF8 bytes to any attached console and garbles terminals.
  Always launch with `-NoNewWindow -RedirectStandardOutput <file> -RedirectStandardError <file>` and read
  those files only when debugging; never let Godot output reach the terminal or the agent.
- The editor normalizes `project.godot` on export; settings equal to defaults get stripped silently.
- `DynamicFont` needs `use_filter = true` plus `extra_spacing_top/bottom` or glyphs lose pixel rows.
- Controls under a `Node2D` move with the camera; screen-space UI must live under `UILayer`.
- PowerShell `&` does not wait for GUI-subsystem exes (Godot): every run leaks a zombie process.
  Always launch with `Start-Process -Wait -NoNewWindow` plus stdout/stderr redirects and `--quit-after 300`.

## Update from upstream

1. Find the iframe URL in the itch page HTML (`html.itch.zone` or `html-classic.itch.zone`), e.g. build 7047666.
2. Re-download `index.html`, `index.js`, `index.wasm`, icons, and the pack into `upstream/`.
3. Decompile the new pack: `& ../tools/gdre/gdre_tools.exe --headless --recover=upstream/index.pck --output=src-new` (replaces `src/`).
4. Re-apply the mods on top of the decompiled base; this repo's `src/` is the reference.

## Rebuild the pack

1. Edit `src/` (tabs; GDScript 1.0 — Godot 3 APIs only).
1b. If art under `src/Art` changed, reimport first: `$godot` with `'--path','src','--editor','--quit-after','30'`;
    the editor does NOT auto-quit — kill it with `Stop-Process -Name "Godot_v3.5.1-stable_win64" -Force`.
2. Validate headlessly (set `$godot = '..\tools\godot-3.5.1\Godot_v3.5.1-stable_win64.exe'` once):
    `$env:IXION_SHOT='1'; Start-Process -FilePath $godot -ArgumentList '--no-window','--path','src','--quit-after','300' -Wait -NoNewWindow -RedirectStandardOutput "$env:TEMP/godot-out.txt" -RedirectStandardError "$env:TEMP/godot-err.txt"`
    (writes `shot.png` at the repo root; `IXION_HOVER_TEST=1` also places a hovered Stockpile - Large; then check the godot.log above). Kill leaks with
    `Stop-Process -Name "Godot_v3.5.1-stable_win64" -Force`.
3. Export pack (output path is relative to `src/`; lands in `src/index.pck` — move it up; no templates needed):
    `Start-Process -FilePath $godot -ArgumentList '--no-window','--path','src','--export-pack','HTML5','index.pck' -Wait -WindowStyle Hidden`
4. Update `index.pck` size in `index.html` (`GODOT_CONFIG.fileSizes`), then run
    `powershell -NoProfile -ExecutionPolicy Bypass -File rebuild-embeds.ps1`.
5. Commit.

## Icons

`Art/Resources/*.png` — all 16 icons redrawn via the Qwen image model: flat transparent 128px glyphs, no gray boxes;
generated on pure magenta and chroma-keyed to alpha. Scripts live in the sibling `tools/icon-redraw/`:
`icon_runner.py` (endpoint `https://token-plan.ap-southeast-1.maas.aliyuncs.com`, key via `QWEN_API_KEY`,
models `qwen-image-3.0-pro` / `wan2.7-image-pro`, 1024x1024) and `postprocess_icons.ps1`
(chroma-key background removal by color distance, crop, 6% pad, downscale to 128px).

## Repo rules

- `index.js` is upstream-minified — never hand-edit. Mirrored binaries stay byte-identical unless
  documenting a deliberate swap (root `index.html` is the runner; the upstream wrapper is archived in
  `upstream/` because itch's `htmlgame.js` is hotlink-protected).
- Controls: LMB place/move, R rotate, RMB/Esc cancel/delete.
